# ERP CEDEP | Treinei, Passei!

Sistema financeiro e administrativo para gestão do CEDEP Cursos.

## Módulos

- Dashboard financeiro por competência
- Receitas, despesas e bancos
- Contas a pagar e receber
- Importação de planilhas Excel
- Cadastros de alunos, responsáveis e parceiros
- Cursos, planos e mensalidades individuais
- Professores, aulas, auxílios e relatórios de pagamento
- Secretaria e controle de caixa
- Contratos, comprovantes e carnês com PIX
- Relatórios e exportação
- Usuários, permissões, backup e sincronização online

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

As variáveis necessárias estão documentadas em `.env.example`.
